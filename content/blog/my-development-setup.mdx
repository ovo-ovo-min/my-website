## 开发工具

### VS Code

Visual Studio Code 是我日常使用的编辑器。以下是我常用的配置和插件：

**主题相关：**

```json
{
  "workbench.colorTheme": "One Dark Pro",
  "editor.fontFamily": "JetBrains Mono",
  "editor.fontSize": 14,
  "editor.lineHeight": 1.6
}
```

**常用扩展：**

1. **ESLint** —— 代码规范检查
2. **Prettier** —— 代码格式化
3. **Tailwind CSS IntelliSense** —— Tailwind 类名补全
4. **GitLens** —— Git 历史可视化
5. **Error Lens** —— 内联错误提示

### 终端

使用 Windows Terminal 搭配 PowerShell 7：

```powershell
# oh-my-posh 主题配置
oh-my-posh init pwsh --config ~/theme.json | Invoke-Expression
```

## 工作流

### Git 提交规范

我采用 Conventional Commits 规范：

```
feat: 新功能
fix: 修复 Bug
refactor: 重构
docs: 文档更新
style: 样式修改
chore: 其他杂项
```

### 开发流程

1. 从 `main` 分支创建 feature 分支
2. 在 feature 分支上开发
3. 提交时遵循提交规范
4. 创建 Pull Request
5. Code Review 后合并
